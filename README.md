# Pastil sa Daet Website

A web project for **Pastil sa Daet**, a local food business in Daet. This repository currently contains the **frontend/static website** and is still under development. A backend will be added in future updates.

## Project Status

🚧 **In Progress** – Frontend pages are being developed. Backend integration is planned.

## Project Overview

The goal of this project is to build a website where customers can learn about Pastil sa Daet, browse the menu, and place orders online. Right now, the project focuses on the user interface and page layout.

## Current Pages

- **Home** (`index.html`) – Landing page / main page
- **Menu & Order** (`menu.html`) – Menu and ordering page
- **About Us** (`about.html`) – Information about Pastil sa Daet
- **Contact** (`contact.html`) – Contact page
- **Sign In** (`signin.html`) – User sign-in page
- **Create Account** (`createAccount.html`) – Account registration page

## Getting Started

### View the Website

1. Clone or download this repository.
2. Open `index.html` in your browser.

Since this is currently a static frontend project, no server setup is required.

### Build Custom CSS (Optional)

If you make changes to the SCSS files, run:

```bash
npm install
npm run build:css
```
